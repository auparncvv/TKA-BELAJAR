# Belajar Materi TKA
Web statis (tanpa build). Upload semua isi folder ini ke repo GitHub, lalu aktifkan **Settings > Pages > Deploy from branch (main, /root)**.

- `data/data.js` : materi (T) dan daftar soal per paket (P). Tambah paket baru = tambah satu objek di P.

- Video YouTube default berupa pencarian per materi. Untuk video pilihan, tambah `v:[["Judul","https://youtu.be/..."]]` pada materi di `data.js`.
- `assets/preview.mp4` : video preview di bagian atas.
